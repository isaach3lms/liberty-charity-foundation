# Liberty Charity Foundation

Flask marketing site. Four pages, static content, one dynamic route (contact form to email). No database.

## Stack

- Flask 3 served by gunicorn
- Jinja templates, hand written CSS, ~30 lines of vanilla JS
- Deployed on Render from Git with auto deploy on push
- Contact form sends via SMTP. Nothing is stored.

## Pages

| Route | Page |
|---|---|
| `/` | Home |
| `/about` | About |
| `/our-work` | Our work |
| `/contact` | Contact |
| `/contact/thank-you` | Confirmation |
| `/healthz` | Render health check |

## Run locally

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
export SECRET_KEY=dev
python app.py          # http://127.0.0.1:5000
```

With SMTP unset, form submissions log to the console instead of sending. Everything else works.

## Deploy to Render

1. Push this folder to a new GitHub repo.
2. In Render: New > Blueprint, point it at the repo. `render.yaml` configures the service.
3. Set these environment variables in the Render dashboard:

| Variable | Value |
|---|---|
| `SECRET_KEY` | auto generated by Render |
| `CONTACT_EMAIL` | inbox that receives submissions |
| `SMTP_HOST` | e.g. `smtp.sendgrid.net` |
| `SMTP_PORT` | `587` |
| `SMTP_USER` | e.g. `apikey` |
| `SMTP_PASS` | provider API key or password |
| `MAIL_FROM` | verified sending address on your domain |

4. Point the domain at Render under Settings > Custom Domain, then add the CNAME at your registrar.

## Editing content

Copy for programs, projects, and the four stage framework lives in the `PROGRAMS`, `PROJECTS`,
and `STAGES` lists at the top of `app.py`. Edit there and every page updates. Page specific
prose is in the templates.

## Replacing photography

Drop new files in `static/img/` using the same naming pattern (`{name}-1800.jpg` and
`{name}-900.jpg`), then update the `photo` key on the relevant project in `app.py`.
